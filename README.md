# 📈 A-Stock Studio 股票智能分析工作台

**基于 AI 大模型的 A 股智能分析 + 同花顺投资账本持仓同步管理系统**

从「每日 AI 决策报告」到「实盘持仓管理」，一个工作台全部搞定。

> 📌 本项目基于 [daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis)（MIT License）二次开发。在原项目强大的 **AI 智能分析** 能力之上，进一步深度定制了 **同花顺投资账本持仓同步、实盘持仓管理、分享卡片、告警通知** 等实盘管理功能，感谢原作者的出色工作。

## ✨ 核心功能

### 1️⃣ 同花顺投资账本同步（本项目特色）

无需手动录入手动持仓，直接对接你的同花顺投资账本：

- **扫码登录**：内置扫码登录页，手机同花顺 App 一扫即登录，登录态本地保存
- **汇总持仓同步**：一键同步账本全部券商账户的汇总持仓（数量 + 成本以账本为准）
- **交易流水同步**：覆盖买入/卖出、逆回购、分红、股息税、银证转账等全类别交易记录
- **导出文件同步**：每天收盘后从账本「数据导出」下载的 `汇总持仓.xlsx` 可直接导入；支持目录自动检测（每 10 分钟扫描）、文件指纹判重，未变化不重复同步
- **智能同步策略**：交易流水采用 **7 个交易日窗口覆盖**，只增量更新，不重建历史，防止数据丢失
- **对账校验**：网页持仓市值 vs 本地持仓市值、现金差额逐项核对

### 2️⃣ 实盘持仓管理

- **多账户持仓**：支持多券商账户汇总展示，账户列可折叠隐藏
- **今日盈亏 / 持有盈亏**：含金额与比例，与账本数据保持一致
- **总资产 / 总市值 / 总现金**：一目了然
- **行业集中度环形图**：按行业聚合持仓占比，直观看到行业分布
- **资产曲线**：总资产历史走势折线图，支持 30/90/180/365 天及全部区间，含区间收益率
- **对账单**：完整的交易明细、分红明细、股息税记录，最新记录置顶，支持按时间范围筛选
- **行情引用策略**：盘中用腾讯实时行情（(现价−昨收)×数量），盘后优先用账本导出快照，收盘价为准

### 3️⃣ AI 智能分析（继承上游能力）

- **每日决策报告**：核心结论、评分、趋势、买卖点位、风险预警、催化剂因素、操作检查清单
- **多市场覆盖**：A股、港股、美股、日股、韩股、台股及 ETF，支持行情、K线、技术指标、新闻、公告、基本面
- **Agent 策略问股**：多轮追问，支持均线、缠论、波浪、趋势、热点、事件、成长、预期等 15 种内置策略
- **智能导入补全**：图片、CSV/Excel、剪贴板导入，股票代码/名称/拼音/别名自动补全
- **CCI 指标信号**：内置东财同款 CCI 指标（TYP、AVEDEV 算法），输出买入/卖出信号与建议价格

### 4️⃣ 告警与通知

- **告警规则**：价格上穿/下穿、涨跌幅、CCI 信号等自定义告警
- **多通道推送**：Bark 推送（手机实时通知）、自定义 Webhook（支持 Bearer Token、Body 模板），可自定义铃声与通知图标

### 5️⃣ 便捷部署与访问

- **局域网访问**：电脑启动后，手机/其他设备可通过局域网 IP 直接访问
- **防待机**：锁屏/合盖不影响服务运行（需配置系统电源计划）
- **深浅色主题**、中英文切换、响应式移动端适配

## 🚀 快速开始

### 本地运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，至少配置一个 AI 模型 API Key

# 3. 启动（仅 Web UI）
python main.py --webui-only
# 默认访问 http://localhost:8000
```

### 登录持仓管理

1. 打开 Web UI →「数据同步」
2. 点击「获取扫码二维码」，用同花顺 App 扫码登录
3. 登录后即可一键同步汇总持仓与交易流水
4. 每天收盘后从账本「汇总持仓 → 数据导出」下载 `汇总持仓.xlsx`，放入配置的下载目录即可自动同步
