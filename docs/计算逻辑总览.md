# SEA 计算逻辑总览（数据源 × 公式 × 验证）

> 结论先行：同花顺账本只提供 **【持仓数据】**【交易记录】两张原始表，其余全部为本系统推算。
> 本文档逐字段标注来源与公式，确保推算逻辑正确、可复核、可对账。

---

| 数据 | 来源 | 性质 |

## 二、核心公式与验证

### 1. 现金
```
total_cash = Σ 各资金账户 money_remain（接口原始返回）
```
- **状态**：40,137.59（接口值）；用户券商 App 显示 40,136.27，差 **1.32**。
- **结论**：1.32 是账本接口自身的口径差（接口明细合计 vs App 展示口径），本系统只透传接口值，非本地计算错误，无法在本地消除。

### 2. 市值（已验证：734,424.50 与用户 App 一致）
```
市值 = Σ(持仓数量 × 现价)
现价 = 腾讯收盘价（盘后）/ 账本最新价（盘中）
```

### 3. 总权益（已验证：774,562.09，用户 774,560.77，差=现金差 1.32）
```
总权益 = 总现金 + 总市值
```

### 4. 持有盈亏 / 盈亏率
```
持有盈亏 = Σ(现价 − 成本) × 数量        （接口/快照透传）
持有盈亏率 = (现价 − 成本) / 成本
```

### 5. 当日盈亏（positions 与 overview 同口径，已验证加总一致）
```
当日盈亏 = Σ 数量 × (现价 − 昨收)
昨收 = 现价 / (1 + 当日涨跌幅)，按现价小数位舍入
positions 逐票 day_pnl 加总 = overview.day_pnl（复算差 0.00）
```

### 6. 月度收益率（Modified Dietz，已验证对齐账本 App ±0.2）
```
月收益 = (期末权益 − 期初权益 − 净出入金) / (期初权益 + 出入金加权)
出入金：银行转证券/银行转存 = 入金（正），证券转银行/银行转取 = 出金（负）
出入金加权 = Σ 出入金 × (剩余天数 / 当月天数)
```
- 用户核对值：10月1.49 / 9月−5.47 / 8月2.65 / 7月7.45 / 6月−8.91 / 5月−0.81 / 4月−0.78 / 3月−2.67 / 2月3.53 / 1月8.44
- 本系统：10月1.49 / 9月−5.40 / 8月2.71 / 7月7.41 / 6月−8.93 / 5月−0.65 / 4月−0.93 / 3月−2.73 / 2月3.53 / 1月8.40（±0.2 内，加权时点口径差异）

### 7. 年度收益率（已验证：3.64，用户 3.67）
```
年度收益率 = Π(1 + 月收益率) − 1
```

### 8. 逐票资金穿透（positions 增强字段）
```
累计买入 cum_buy      = Σ(买入 + 新股入帐 + 股份转入 + 转债转入)          [导入流水，金额取绝对值]
累计卖出 cum_sell     = Σ(卖出)
累计分红 cum_dividend = Σ(除权除息)   ← 与账本「累计分红」口径一致，不扣股息个税
净沉没本金 net_sunk_cost = cum_buy − cum_sell − cum_dividend
回本涨幅 break_even_pct = (成本 − 现价) / 现价 × 100
持仓天数 hold_days    = 今天 − 最早买入日
```
- 验证（vs 用户 v3.0 报告穿透表）：三九/有色ETF/农业/龙盛 分位级一致；广核/铜陵/五洲累计买卖与旧报告差数千~数万元——**原因是旧报告所用导出文件与最新导入文件版本不同（导入去重导致笔数差异），以本库最新导入为准**。

### 9. 费用 / 税费
```
fee_total = Σ(买入/卖出记录的"费用"列)      → 4,751.27
tax_total = Σ(股息个税征收)                → 1,424.41
```

### 10. 已实现盈亏（overview.realized_pnl = 已清仓合计）
```
overview.realized_pnl = Σ closed_positions.total_pnl = 136,571.88（182 笔，券商原始）
```
- 已实现盈亏以「已清仓合计」为锚（券商原始数据可核），不再依赖手动录入流水（表空→旧口径恒 0）。
- 当前持仓的历史波段已实现盈亏：见 positions.cum_buy/cum_sell/cum_dividend/net_sunk_cost。

### 11. 资产曲线（equity_curve）
```
return_pct      = TWR（时间加权，剔除期间净出入金）         → -4.96%
simple_return_pct = (期末权益 − 期初权益) / 期初权益          → 2.59%
```
- 两值口径不同：-4.96% 剔出入金（真实投资收益率），2.59% 为起止点简单环比（含出入金）。
- **TWR 净出入金来源**：正常快照日取 payload.net_cashflow（持仓同步时写入）；equity_only 日（资产曲线）由同步器 `_import_asset_trend` 从导入流水银证转账按日聚合写入（银行转证券/银行转存=入金+，证券转银行/银行转取=出金−），**防止把入金算成收益**（旧 0.72% 曾把 9-29 的 +4 万入金算成收益，修正后 -4.96%）。
- **equity_only 快照**（仅资产曲线、无持仓/现金拆分的日子，如 2026-07-28~10-08）：`total_market_value`/`total_cash` 输出 `null`，不再把"权益"伪装成"市值"。

## 三、数据链路（一次同步发生了什么）

```
同花顺账本导出文件（持仓/交易记录/已清仓）
   │ 导入（全量覆盖 + dedup 去重）
   ▼
portfolio_import_records（交易流水全类别）
   │ 聚合
   ├─ positions 逐票穿透（cum_* / net_sunk_cost / hold_days）
   ├─ fee_total / tax_total
   ├─ 月度/年度收益率（银证转账出入金 + Modified Dietz）
   └─ recent_trades / recent_trade_stats / dividends / cash_flows

同花顺账本接口（实时）
   │ 同步
   ▼
每日快照（现金 money_remain / 持仓成本 / 持有盈亏）
   │ 兜底
   ├─ 现金校正只读"最近正常快照"（防止被资产曲线 equity_only 污染）
   └─ 重放现金失真（>1000 元）时沿用快照现金并重算权益
```

## 四、已知偏差清单（透明声明）

| # | 项目 | 偏差 | 原因 | 处置 |
|---|---|---|---|---|
| 1 | 现金 | 40,137.59 vs App 40,136.27（1.32） | 接口「资金余额」含 1.32 逆回购应计利息（9-29 有 4 万 GC001），App「可用资金」不含未到账利息；接口 7 账户明细已核实（中山 40,134.29 + 6 零散账户 3.30，App = 40,134.29 + (3.30−1.32)） | 只透传接口值，不做本地修正 |
